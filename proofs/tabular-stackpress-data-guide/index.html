GUIDEBOOK RULES

What the Proof taught us

These are implementation constraints discovered by making the fixture fail safely.

01

Catalog, don’t generate

Dynamic user tables are discovered at runtime. Fixed Tabular records alone belong in generated schemas.

02

Intersect authority

The app can narrow access. PostgreSQL grants and forced RLS remain the final authority.

03

Separate migration power

A non-caller owner performs DDL, whole-table promotion, and shared-view publication.

04

Version every commit

Mutations carry an expected version; stale writers receive a conflict, never a silent overwrite.

05

Persist invalid work

Drafts and validation errors live in the Tabular schema without corrupting canonical records.

06

Translate every PGlite claim

Pool, network, server version, multi-worker, and operations claims wait for their real targets.
